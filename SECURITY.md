# Security policy

## Supported version

`0.1.x` is the only supported line.

## Reporting a vulnerability

Please use a private [GitHub security advisory](https://github.com/eversko/dsh-blackbox/security/advisories/new). Do not include private session artifacts, prompts, credentials, tool arguments, or tool results in a public issue.

Include the Black Box version, Node version, DSH version, operating system, and the smallest metadata-only reproduction possible. We will acknowledge a valid report before discussing public disclosure timing.
